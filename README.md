# UAvalut

ユニオンアリーナを、ブラウザ上で遊ぶための **手動効果処理式シミュレータ** です。
カードの効果は自動処理しません。カードのテキストを読んで、盤面のカードを人が動かします。

サーバーは不要です。`index.html` をブラウザで開けば動きます。

---

## 1. ファイル構成

| ファイル / フォルダ | 内容 |
|---|---|
| `index.html` | 本体。デッキ構築・一人回し・友人と対戦のすべてが入った1枚のファイル |
| `cards-data.js` | 全カードのデータ。`const CARD_DATA=[...]` の形式 |
| `images/` | カード画像（WebP）。ファイル名はカード番号の `/` を `_` に置き換えたもの |
| `Card_data_make/get_card.py` | 公式サイトからカードを取得し、WebPに変換して `images/` に入れるツール |
| `Card_data_make/make_cards_data.py` | 取得したJSONから `cards-data.js` を作り直すツール |
| `Card_data_make/convert_images.py` | 既存の `images/` フォルダをまとめてWebPに変換し直す時だけ使う（通常は不要） |

`index.html` / `cards-data.js` / `images/` の3つが同じ場所に揃っていれば動きます。

---

## 2. 使い方

### 起動

`index.html` をダブルクリックしてブラウザで開きます。メニューが表示されます。

### デッキ構築

1. メニューから「デッキ構築」を選び、「＋ 新規作成」を押します
2. 左上の **作品を選択** します（作品を選ぶまでカード一覧は出ません）
3. 色・必要エナジー・種類・トリガー・キーワードで絞り込めます
4. 「**パラレルを非表示にする**」ボタンで、パラレル（`_p1` 等）を一覧から隠せます。もう一度押すと戻ります
5. カードの下の「− 枚数 ＋」で枚数を変えます。カード画像をクリックすると詳細が出ます
6. 右側に枚数と検証結果（50枚・作品の混在・トリガー4枚制限・同名カードの上限）が出ます
7. 「このブラウザに保存」で保存します。保存先はブラウザのlocalStorageです

デッキコードで書き出し・読み込みもできます（`カード番号*枚数` をカンマ区切り）。

> パラレルは通常版と合算して枚数を数えます。通常版4枚＋パラレル1枚は入りません。

### 一人回し

メニューの「一人回し」から、自分側・相手側のデッキと先攻を選んで開始します。

| 操作 | 内容 |
|---|---|
| 左クリック | カードを選択（もう一度押すと解除）。左パネルに詳細が出る |
| 左クリック（複数） | 最大12枚まで選べる。⊕ を押すと選んだ順にまとめて移動する |
| ⊕ここに | 選択中に各ゾーンへ出現するボタン。押すとそこへ移動する |
| 右クリック | カードの操作メニュー（下記） |
| ⚔ ボタン | 自ターンならアタック宣言、相手ターンならブロック宣言。カードは自動でレストになる |

**カードの右クリックメニュー**

- 公開する / アクティブ・レスト切替 / 表裏切替
- レイド（場のカードを右クリックし、選択中のカードをその上に重ねる。重ねた側は自動でアクティブ）
- 束を見る（重なったカードを1枚ずつ操作する）
- **BP +1000 / +500 / −500 / −1000**（カードにBP修正のラベルが付く）
- **特殊能力を追加**（下記）
- BPメモ・特殊能力をターン終了で消すかどうかの切替

**特殊能力の付与**

カードを右クリックして「特殊能力を追加」を押すと、能力の一覧がチェックボックスで出ます。
選んで「決定」を押すと、BPメモと同じようにカードにラベルが付きます。効果の処理そのものは手動で行ってください。

付けられる能力：インパクト（数値）／インパクト無効／ダメージ（数値）／ステップ／狙い撃ち／
2回アタック／2回ブロック／ブロックされない／ブロックできない／アタックできない／
選ばれない／効果を受けない／退場しない

数値欄には `1` や `+1` のように入力します。
付けた能力は**既定ではターン終了時に消えます**。持続する能力に使う場合は、右クリックメニューの
「BPメモ・特殊能力:ターン終了で消える／残す」を「残す」に切り替えてください。

> アクティブにならない状態は、右のサイドバーの「フリーズ指定 / 解除」を使ってください。
> 次にアクティブになるタイミングを1回だけ飛ばして、自動で解除されます。

### 友人と対戦

合言葉で部屋を作り、Firebase経由で盤面を同期します。インターネット接続が必要です。
どちらか1人が「部屋を作る」を押し、もう1人が同じ合言葉で「部屋に入る」を押します。

## 3. カードを追加する手順（新弾が出たとき）

新しい弾のカードを追加するときは、次の3ステップです。

### 準備（初回のみ）

コマンドプロンプト（または PowerShell）で、必要なものを入れます。

```
pip install playwright pillow
playwright install chromium
```

### ステップ1：公式サイトからカードを取得する

1. `Card_data_make/get_card.py` をテキストエディタで開きます
2. 中ほどの `SERIES_LIST = [` の中から、**追加したい弾の行だけ先頭の `#` を外します**
   （すでに取得済みの弾は `#` を付けたままにしてください。全部外すと数時間かかります）

   ```python
   #("570153", "チェンソーマン UA53BT"),
   ("570055", "アイマス シンデレラ UA55ST"), ("570155", "アイマス シンデレラ UA55BT"),   ← この行だけ有効
   ```

3. `Card_data_make` フォルダに移動して実行します

   ```
   cd Card_data_make
   python get_card.py
   ```

これで次の処理が**一度に**行われます。

- カード情報を取得 → `Card_data_make/cards_data/<シリーズ名>.json` に保存
- カード画像をダウンロード → その場でWebPに変換 → **`images/` フォルダへ直接保存**

途中で止めても、すでにWebPがある画像は飛ばして続きから進みます。
変換前のPNGはディスクに残りません（残したい場合はスクリプト上部の `SAVE_ORIGINAL_PNG` を `True` に）。

弾の値（`570155` などの6桁）が分からない場合は、公式サイトのカードリストで弾を選び、
`#series` の選択肢の value を確認してください。

### ステップ2：cards-data.js を作り直す

`Card_data_make/make_cards_data.py` は、**同じフォルダにある `*.json` を全部読み込んで** `cards-data.js` を作ります。
そのため、**過去に取得した弾のJSONも同じ場所に揃っている必要があります**。

1. これまでに取得した全弾のJSONと、今回追加したJSONを1つのフォルダに集めます
   （`Card_data_make/cards_data/` にまとめるのが分かりやすいです）
2. そのフォルダに `make_cards_data.py` を置いて実行します

   ```
   cd Card_data_make\cards_data
   python ..\make_cards_data.py
   ```

   > 上のように親フォルダのスクリプトを指定して実行しても、
   > JSONの読み込みと `cards-data.js` の出力は**カレントフォルダ**（＝`cards_data`）が対象になります。

3. 「完了: ○○枚 / ○○作品 -> cards-data.js」と出れば成功です

**一部の弾のJSONしか無い状態で実行すると、その分だけの `cards-data.js` になります**。
以前より枚数が減っていたら、JSONが揃っていない可能性が高いので確認してください。

### ステップ3：cards-data.js を差し替える

出来上がった `cards-data.js` を、`index.html` と同じ場所に上書きコピーします。

以上です。`index.html` は触る必要がありません。ブラウザを再読み込みすれば新しい弾が選べます。

### 確認

1. `index.html` を開き、デッキ構築で作品のプルダウンに新しい作品が出るか確認します
2. カード画像がグレーの枠ではなく、ちゃんと表示されるか確認します
   （画像が無いカードは、カード名とBPのテキスト表示に自動で切り替わります）

---

## 4. うまくいかないときは

| 症状 | 確認すること |
|---|---|
| カード画像が出ず、テキストだけになる | `images/` の中に `<カード番号の / を _ にしたもの>.webp` があるか。`index.html` と同じ階層に `images/` があるか |
| 新しい弾が作品のプルダウンに出ない | `cards-data.js` を上書きし忘れていないか。ブラウザを強制再読み込み（Ctrl+F5）したか |
| カード枚数が前より減った | ステップ2で、過去の弾のJSONが同じフォルダに揃っていない |
| `get_card.py` でエラーが出て止まる | 弾ごとにエラーを飛ばして次へ進む作りなので、最後まで走らせて失敗した弾だけ取り直してください |
| `playwright` が見つからない | `pip install playwright` と `playwright install chromium` の両方を実行したか |
| 保存したデッキが消えた | デッキはブラウザのlocalStorageに保存されます。別のブラウザ・シークレットウィンドウでは見えません |

---

## 5. 補足

- デッキ構築の一覧では、アクションポイントカードは除外されています
- カード画像は横幅400px・品質82のWebPに縮小しています。画質を変えたい場合は `get_card.py` の `MAX_W` と `QUALITY` を書き換えてください
- `convert_images.py` は、`get_card.py` を統合する前に取得した既存の `images/` をまとめて変換し直すためのものです。新しくカードを追加するだけなら使いません
- 身内での利用を前提にしています
